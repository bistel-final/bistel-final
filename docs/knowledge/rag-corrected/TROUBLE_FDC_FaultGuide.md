# FDC 이상 유형 진단 및 조치 가이드

PHOTO와 ETCH 공정에서 발생한 이상을 이해하고 점검 범위를 정하기 위한 안내 문서다. 실제 설비 제어와 최종 조치는 정해진 승인 절차에 따른다.

## 1. 이상 상태 이해하기

| 상태 | 의미 | 우선 확인 사항 |
|---|---|---|
| 정상 범위 | 측정값과 공정 추세가 안정적임 | 정기 점검 유지 |
| 관리 범위 이탈 | 평균 추세가 평소 관리 범위를 벗어남 | 공정 조건과 최근 변화 확인 |
| 규격 이탈 (R01) | 원시 측정 한 점이 허용 규격을 벗어남 | TRACE OOS 알람과 해당 웨이퍼 즉시 확인 |
| 반복 이상 (R03) | 같은 챔버·파라미터·공정 단계의 OOS가 연속 3개 웨이퍼에 도달 | 챔버 집중 점검 및 승인 절차 검토 |

반사파(`ET_REFL`)는 낮을수록 바람직한 항목이므로, 높아지는 방향을 중점적으로 관리한다.

### 1.1 R01 — 단일 규격 이탈

원시(raw) 측정 한 점이 상한 규격(USL) 또는 하한 규격(LSL)을 벗어나면 즉시 TRACE OOS 알람으로 기록한다. 상한 중심 관리 항목인 `ET_REFL`은 상한 규격만 평가한다.

### 1.2 R03 — 반복 OOS

R03는 같은 챔버·파라미터·공정 단계(`recipe_step_no`)의 TRACE OOS만 대상으로 한다. 챔버 누적 처리 순번(`chamber_wafer_cum`)을 기준으로 LOT 경계를 넘어 연속성을 계산하며, OOS가 아닌 항목이 나오면 연속 수를 초기화한다. 서로 다른 파라미터 또는 공정 단계의 OOS는 합산하지 않는다.

연속 OOS가 3개에 최초 도달한 시점에만 R03를 한 번 생성한다. R03 근거에는 연속 OOS 웨이퍼 3개와 해당 웨이퍼의 같은 파라미터·공정 단계 TRACE 알람 근거가 포함된다. 최종 기준 데이터에서 R03 한 건은 TRACE 알람 근거 9개를 가진다.

## 2. 이상 확인 순서

1. 이상이 발생한 설비, 챔버, 파라미터와 공정 단계를 확인한다.
2. 단발 이상인지, 같은 챔버에서 반복되는 이상인지 확인한다.
3. 같은 설비의 다른 챔버와 비교해 챔버 고유 문제인지 장비 공통 문제인지 살핀다.
4. 계측 결과와 앞뒤 공정 이력을 함께 확인해 상류 공정 영향 가능성을 검토한다.
5. 아래 조치 기준에 따라 관찰, 경고 또는 승인 절차를 진행한다.

## 3. 대표 이상 유형별 진단

### 3.1 FOC — Focus Excursion (포커스 이탈)

`PH_FOCUS` 이상은 `FOC` 후보로 우선 검토한다. 초점이 벗어나면 패턴 경계가 흐려지고 CD가 작아질 수 있다. 웨이퍼 척 표면 이물, 웨이퍼 평탄도 편차, 포커스 센서 교정 상태를 우선 확인한다.

### 3.2 RFM — RF Mismatch (RF 정합 이상)

`ET_REFL` 이상은 `RFM` 후보로 우선 검토한다. 반사파가 증가하면 플라즈마에 전달되는 실효 전력이 줄어 식각 부족으로 이어질 수 있다. 정합기 튜닝 상태, 챔버 내벽 폴리머 누적, 상부 전극 상태를 확인한다.

### 3.3 MFD — MFC Flow Drift (가스 유량 이탈)

`ET_CF4` 이상은 `MFD` 후보로 우선 검토한다. CF4 유량이 부족하거나 과다하면 식각 반응 조건이 바뀔 수 있다. MFC 교정 상태, 가스 배관의 미세 누설, 가스 공급 계통을 확인한다.

### 3.4 TMD — ESC Temperature Deviation (정전척 온도 이상)

`ET_ESC` 이상은 `TMD` 후보로 우선 검토한다. 정전척 온도 이탈은 웨이퍼 위치별 식각 속도 차이를 만들 수 있다. He 가스 누설, 냉각수 유량, 정전척 표면 상태를 확인한다.

### 3.5 고정 유형이 없는 이상 (OTH)

`PH_DOSE`, `PH_PEB`, `PH_DEV`, `ET_PRES`는 단일 항목 이탈만으로 특정 이상 유형을 단정하지 않는다. 다른 이상 징후와 설비 상태를 함께 확인한 뒤에도 분류하기 어려운 경우에만 `OTH`(Other) 복합 또는 미분류 이상 후보로 기록한다.

## 4. 상류 공정 영향 확인

ETCH 단계의 CD 이상이 확인되더라도 ETCH 설비를 곧바로 원인으로 단정하지 않는다. PHOTO 단계의 노광 조건, 포커스, 현상 조건이 이후 ETCH 결과에 영향을 줄 수 있기 때문이다.

1. 문제가 발생한 웨이퍼의 PHOTO 처리 이력을 확인한다.
2. PHOTO 파라미터에 이상 징후가 있었는지 확인한다.
3. ETCH 파라미터와 계측 결과를 함께 비교한다.
4. 한 공정의 이상만으로 다른 공정의 원인을 확정하지 않는다.

## 5. 업무 조치 기준

| 관측 상황 | 권고 조치 | 설명 |
|---|---|---|
| SUMMARY OOC만 존재 | `MONITORING` | 조건 변화와 다음 생산 결과를 관찰한다. |
| TRACE OOS가 있고 R03는 없음 | `WARNING` | 담당자에게 알리고 설비·챔버 점검을 진행한다. |
| strict R03가 존재 | `EQP_HOLD` | 설비 투입 보류를 검토하며 사람의 승인이 필요하다. |

`EQP_HOLD`는 강한 조치이므로 R03가 있으면 n8n 승인 요청 EMAIL을 보내고 사람의 승인을 기다린다. 승인 전에는 Kafka MES Mock 실행을 요청하지 않으며, 승인된 `EQP_HOLD`만 Kafka MES Mock 실행을 요청한다. 이상 유형, 계측 결과, 챔버 비교는 점검 범위를 정하는 데 사용하며 조치 기준을 임의로 바꾸는 근거로 사용하지 않는다.

## 6. 점검 권고에 포함할 내용

- 이상이 관측된 파라미터와 공정 단계
- 대상 설비와 챔버
- 단발 이상 또는 반복 이상 여부
- 의심 원인과 우선 점검 항목
- 상류 공정 영향 확인 필요 여부
- 권고 조치와 승인 필요 여부

원인 후보는 확정 사실처럼 표현하지 않고, “확인 필요”, “가능성” 등의 표현으로 구분한다.

## 7. 진단 요약표

| 대표 파라미터 | 확인할 이상 유형 | 우선 점검 범위 |
|---|---|---|
| `PH_FOCUS` | 포커스 이탈 | 척, 웨이퍼 평탄도, 포커스 센서 |
| `ET_REFL` | RF 정합 이상 | 정합기, 챔버 내벽, 상부 전극 |
| `ET_CF4` | 가스 유량 이탈 | MFC, 배관, 가스 공급 계통 |
| `ET_ESC` | 정전척 온도 이상 | He 가스, 냉각수, 정전척 표면 |
| `PH_DOSE`, `PH_PEB`, `PH_DEV`, `ET_PRES` | 복합 확인 필요 | 관련 조건과 다른 이상 징후 함께 확인 |
